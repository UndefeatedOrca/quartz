The work is starting to compile
We'll see the end result
If all goes well I'll have something
That isn't an insult

But first I have some labor long
Extracting all the things
So that when final product is
Completed it will sing

So hold your horses if you can
Bear with me if you please
So that when future days arrive
We witness victories
