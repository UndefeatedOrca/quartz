There's lots to say 'bout Google Docs
And not all of it's good
But if you need to edit things
Use Google Docs you should

Those clean green lines and blue checkmarks
Are simple and serene
Compared to Word's red boxy things
Toward Google Docs I lean

And so while I don't like G-Suite
Assessed in aggregate
When I am touching up writing
It can be pretty great
