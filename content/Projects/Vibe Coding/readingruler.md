I like it when my friends have the tools they need to succeed, both IRL and digitally - as a result, I present [Reading Ruler - Microsoft Edge Addons](https://microsoftedge.microsoft.com/addons/detail/reading-ruler/acdafpagkenenkbmknfgplooilnjejng), a brand new (apparently) unique take on the reading ruler as a browser extension.

Direct download: [reading-guide-extension---v5-1-4.zip](reading-guide-extension---v5-1-4.zip)

Features
- Reading ruler - snap to lines, automatic scroll, automatic sizing, mouse mode (WIP), customizable tint up to "blackout mode"
- Font replacer - Atkinson, Open Dyslexic 3, Lexend, Comic Sans, Verdana
- Custom letter spacing
- Custom line spacing
- Configurable column width
- Alternating paragraph shading
