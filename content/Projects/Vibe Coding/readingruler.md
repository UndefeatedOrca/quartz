I like it when my friends have the tools they need to succeed, both IRL and digitally - as a result, I present [[reading-guide-extension---v5-1-4.zip]], a brand new (apparently) unique take on the reading ruler as a browser extension.

Development is ongoing (I only get so many Claude credits a day), but the core functionality is now there, just load it into your chrome or edge extensions folder and you're off to the races. This is such a seemingly useful tool that I might actually publish it lol.

Features
- Reading ruler - snap to lines, automatic scroll, automatic sizing, mouse mode (WIP), customizable tint up to "blackout mode"
- Font replacer - Atkinson, Open Dyslexic 3, Lexend, Comic Sans, Verdana
- Custom letter spacing
- Custom line spacing
- Configurable column width
- Alternating paragraph shading
