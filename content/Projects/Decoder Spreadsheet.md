During my cipher kick in mid-2025 I devised a spreadsheet that will generate and decode simple substitution ciphers based on an input. It isn't anything super special, but it's a neat application of the VLOOKUP function, and the function to calculate Caesar cipher shifts is one that I'm rather proud of.

You can easily add an alphabet if you want to by adding an entry to the code in use table and the alphabet itself to the corresponding column.
